What you get

Everything you need. Nothing you didn't ask for.

A careful set of defaults, decided once and written down, so you don't have to hunt through settings after every install.

microG instead of Google

Apps that expect Google services keep working through microG. No Google account needed, nothing preinstalled from Google.

F-Droid as the app store

F-Droid is the one built-in store, together with the project's own signed repository. Aurora Store is one tap away in F-Droid if you need Play apps.

Privacy by default

LineageOS statistics are opt-in, network time comes from Germany's national metrology institute PTB, and remaining default connections are documented.

Hardened user build

A real user build with SELinux enforcing and no debuggable system, signed with the project's own keys.

Updates over the air

New builds arrive in Settings → System → Updater, streamed and installed in the background on the inactive slot, with automatic fallback.

Glyph lights work

The rear Glyph interface works with per-app notification and call animations, thanks to the ParanoidGlyph app and a fixed SELinux policy.

Install & update

Updating from an earlier Ithaka OS build

Phones running the 2026-11-03 build or later get new builds in the Updater automatically (Settings → System → Updater). To move up from the 2026-10-14 build once:

  1. Download the zip below and copy it to the phone, then check its SHA-256.
  2. Open Settings → System → Updater, tap ⋮ → Install local update and choose the zip.
  3. When it says Update imported, tap the update, choose Install and wait for the progress bar.
  4. Tap Reboot. The new system starts from the other slot; if it does not boot, the phone falls back automatically.
Check your SIM after the first boot. On the test phone the eSIM had to be switched on again: Settings → Network & internet → eSIM settings → eSIM, then enable the profile under SIMs.

A fresh installation needs an unlocked bootloader and fastboot; it erases the phone. The steps are in the installation guide.
