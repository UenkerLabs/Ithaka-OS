# Roadmap

Decisions as of 2026-11-03. Each build changes one area at a time, so problems can be attributed.

## Next build: current sources

- Tracking build with the upstream changes listed in [UPSTREAM.md](UPSTREAM.md), including the Glyph fixes.
- First build with the built-in update address ([OTA.md](OTA.md)); zips are published on SourceForge.
- Twelve (music player) is left out ([APPS.md](APPS.md)).
- Tangelo OS boot animation: a tangelo slice in dots whose segments fan in, then a dot-matrix "TANGELO" wordmark and a slow ripple while booting; generated by `scripts/gen-bootanimation.py` and swapped in for the LineageOS animation.
- Re-test Glyph, which is faulty on the 2026-10-14 build.

## Build after that: Tangelo OS branding and Infomaniak

- **Name: Tangelo OS**, based on LineageOS 23.2. README, banner and repository (`YZUe1980/tangelo-os`) already use it; the build adds it to Settings and the Updater, and the SourceForge display name follows. Internal identifiers (`lineage-*.zip`, `ro.lineage.*`, release type) stay unchanged so OTA updates keep working. User-visible strings to override include the Updater's `brand_name`, `header_build_version`, `list_build_version` and `list_build_version_date`, in the default and German resources.
- **Infomaniak integration** ([APPS.md](APPS.md)): kSync, Infomaniak Mail and kDrive from F-Droid (fully free editions, no instant push needed); Seedvault backup to the kDrive storage provider.
- **Privacy defaults** and a **hardened `user` build** instead of `userdebug`; details still to be worked out.
